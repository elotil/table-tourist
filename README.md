# Table Tourist

A web-based tool for exploring and inspecting a database.

Built with React, TypeScript, and CFML on Lucee.

## Third-Party Resources

This project uses the following sample databases:

- [Chinook](https://github.com/lerocha/chinook-database), created by Luis Rocha and distributed under the MIT License.
- [Northwind SQLite3](https://github.com/jpwhite3/northwind-SQLite3), a SQLite re-engineering of Microsoft's Northwind sample database by JP White, distributed under the MIT License.
